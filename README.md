# RNProject

A thin example React Native project using the [Rock framework](https://www.rockjs.dev/) for brownfield iOS integration.

## Overview

This project demonstrates how to package a React Native application as reusable XCFrameworks that can be embedded into existing native iOS applications.

## Requirements

- Xcode 26
- Node.js and Yarn
- React Native development environment

## Building XCFrameworks

To package the project for iOS integration, run:

```bash
yarn package:ios
```

This command outputs 3 XCFrameworks that can be embedded in another iOS project:

- React Native core framework
- JavaScript bundle
- Additional dependencies

## Building Android AAR

To package the project for Android integration, run:

```bash
yarn package:aar
```

The generated AAR will be available at:

```
android/rnprojectreact/build/outputs/aar/rnprojectreact-release.aar
```

### Publishing to Maven Local

To publish the AAR to your local Maven repository for use in other Android projects:

```bash
yarn rock publish-local:aar --module-name rnprojectreact
```

Then add the dependency to your Android app's `build.gradle`:

```gradle
dependencies {
    implementation("com.rnprojectreact:rnproject:0.0.1-local")
}
```

### Configuration

If you need to specify a custom Node.js path, add it to `android/local.properties`:

```properties
react.nodeExecutableAndArgs=/path/to/node
```

## Integration

The XCFrameworks generated by this project can be embedded directly into an existing iOS application following the brownfield integration pattern.

For detailed integration instructions, see the [Rock framework brownfield iOS documentation](https://www.rockjs.dev/docs/brownfield/ios).

## Development

```bash
# Install dependencies
yarn install

# Start Metro bundler
yarn start

# Run on iOS
yarn ios

# Run on Android
yarn android
```
